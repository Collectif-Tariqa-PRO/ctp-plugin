ENTREPRENDRE EN MUSULMAN — LE MODE D'EMPLOI

1. Le cap d'abord — écris pour quoi tu fais ça, avant toute décision

2. Le tableau de bord ensuite — une ligne non chiffrable, en premier

3. Chaque outil passe le test des trois leviers avant d'entrer chez toi

4. Chaque contrat passe la question : qui perd quoi si ça tourne mal ?

5. Chaque rythme passe la question : est-ce que je le tiens dans deux ans ?
