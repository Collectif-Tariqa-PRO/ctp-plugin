# Dossier — Installation au Maroc

Mémoire écrite de mon installation au Maroc : ce que j'ai fait, quand, avec qui,
et ce qu'il reste à faire. Objectif : ne plus jamais me déplacer pour rien, et
pouvoir reconstituer l'historique complet quand une administration le demande.

## Comment ce dossier est rangé

| Fichier | Ce qu'il contient |
|---|---|
| `journal.md` | La chronologie. Une entrée par événement, la plus récente en haut. |
| `demarches/` | Une fiche par démarche en cours ou terminée : pièces à fournir, étapes, statut. |
| `contacts.md` | Les personnes, lieux, sites et numéros rencontrés en chemin. |

## Règles du dossier

- **Une entrée à chaud.** Je note le jour même, même en trois lignes.
- **Je ne réécris pas le passé.** Une info corrigée est ajoutée, l'ancienne est
  barrée ou marquée « corrigé le … ».
- **Ce qui n'est pas confirmé est marqué `⚠️ à confirmer`.** Un nom d'administration
  mal entendu ou une URL approximative fait perdre une demi-journée.
- **Aucune pièce d'identité, aucun scan, aucun numéro de passeport dans ce dépôt.**
  Ici on décrit les documents ; on ne les stocke pas.
